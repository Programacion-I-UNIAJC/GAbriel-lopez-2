# 🚀 Bienvenido al Curso de Programación

Este es el **repositorio base** (backing repository) de nuestro curso. Está configurado como un repositorio privado para asegurar que trabajes en tu propio entorno de desarrollo de forma segura y sin interferencias.

## 🛠️ ¿Cómo empezar con GitHub Codespaces?

Para comenzar a programar en el curso, sigue estos pasos:

1. **Crea tu Codespace**: Haz clic en el botón verde que dice **"Code"** (en la parte superior derecha de esta página).
2. **Inicia el entorno**: Selecciona la pestaña **Codespaces** y haz clic en **"Create codespace on main"**.
3. **Espera la configuración**: GitHub preparará tu editor en la nube (Visual Studio Code) con todas las herramientas, extensiones y dependencias que usaremos en las clases. ¡No necesitas instalar nada en tu computadora!

## 📌 Reglas importantes
* **Trabajo Individual**: Este repositorio es privado para proteger tu código. No compartas tus accesos ni descargues el trabajo de otros compañeros.
* **Auto-guardado**: Todo lo que programes en tu Codespace se guarda en la nube vinculado a este repositorio.

¡Mucho éxito en tu aprendizaje! Si tienes dudas, contacta al profesor o tutor del curso.
